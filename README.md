# What is this Repo

This repo contains code used, which has been used to experiment, test and learn about data parallel programming and generally parallel programming, specifically focused on content from the courses Programming Massively Parallel Hardware (PMPH) and Data Parallel Programming (DPP) at the University of Copenhagen. The repo also contains extra material which I have written, evaluated and used myself as extracurricular learning during this time.

# What does this repo contain
The repository focuses on two vastly different ways of doing parallel programming. In one way, it contains CUDA code, both in C++ and Python examples. In these files I focus on writing CUDA kernels and evaluating these against a sequential solution to measure speedup factors and memory throughput. On the other hand, you find Futhark code fragments, a data-parallel programming language that provides more parallel basic blocks for expressing data-parallel programs.
